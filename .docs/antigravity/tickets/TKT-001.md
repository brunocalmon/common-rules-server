# [TKT-001] Implement util/resource_parsing.py

[🏠 Roadmap](../ROADMAP.md) | [⬆️ Epic](../epics/EPC-001.md)

## Descrição
Substituir `rule_parsing.py` por `resource_parsing.py` — parser unificado para todos os kinds (rule, skill, agent, workflow, loop) com suporte a frontmatter YAML e placeholders `{{VAR}}`.

## Critérios de Aceite (Definition of Done)
- [ ] Parser suporta carregar frontmatter YAML com separadores `---`.
- [ ] Parser suporta o schema definido no `rollback_playbook.md` (kind, name, description, relationships, env).
- [ ] Parser não quebra (warnings ou fails gracefullly) quando os campos não obrigatórios não estão presentes.
- [ ] Testes unitários para o parser atualizados/criados.

## Notas de Implementação / Discussões
- O parser deve ser genérico o suficiente para não validar regras de negócio complexas, apenas o formato YAML -> Dict + Body texto.
