# Metodologia de Documentação (Wiki Core + Jira-like Tracker)

[PRD](PRD.md) · [RFC](RFC.md) · [KPI](KPI.md) · [Milestones](MILESTONES.md) · [Usage](USAGE.md) · [Protocol](DOCUMENTATION-PROTOCOL.md) · [Tracker](tracking/ROADMAP.md)

Este diretório contém os templates maduros para qualquer projeto futuro. Ele une uma arquitetura clássica de documentos de engenharia com um sistema Jira-like de tracking na pasta `tracking/`.

## A Regra Central
Sempre obedeça ao **[Protocolo de Documentação](DOCUMENTATION-PROTOCOL.md)**. Documentos velhos nunca são sobrescritos silenciosamente; use os marcadores `[→ overrides]` e atualize retroativamente.

## Diretórios
- `/prd`: Product Requirements Documents (visão, produto, requisitos).
- `/rfc`: Request for Comments (arquitetura técnica, data model).
- `/kpi`: Métricas de sucesso.
- `/tracking`: Onde o trabalho é planejado e executado (Épicos, Tickets, Findings, Roadmap).

Copie estes arquivos e use-os para iniciar qualquer documentação séria.
