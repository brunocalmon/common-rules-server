# [TKT-034] BDD Test Automation (JSON-RPC)

**Epic:** [EPC-004](../epics/EPC-004.md)  
**Status:** Done  
**Cost:** 5  

## Goal
Automate the execution of `agent_bdd.feature` scenarios against the `common_rules_server` directly from the IDE/Python ecosystem without requiring external tools like Karate.

## Context
We need to prove the system behaves as specified in the Gherkin scenarios. However, the system is an MCP server speaking JSON-RPC over stdio. Previous attempts to use `pytest-bdd` and `mcp.client.stdio` ran into complex `asyncio` event loop conflicts resulting in `ExceptionGroup` tear-down errors. The solution needs to isolate the test environment to prevent mutating the real workspace.

## Requirements
- [x] Integrate `pytest-bdd` for Gherkin parsing.
- [x] Isolate the file system for each test using Pytest's `tmp_path` fixture via the `COMMON_RULES_PROJECT_ROOT` env var.
- [x] Create an in-process JSON-RPC client (`SimpleMCPClient`) that spawns the server as a subprocess and speaks synchronous JSON-RPC.
- [x] Map Gherkin `Given/When/Then` steps to Pytest functions dynamically.
- [x] Run and pass the complete test suite.

## Outcome
Implemented `src/test/service/test_agent_bdd.py` containing a robust `SimpleMCPClient`. The suite successfully executes all 64 scenarios in isolation, verifying compliance with the defined Gherkin contracts.
