# TKT-030 — Built-in and user resources compose in setup and sync

**Type:** Feature
**Status:** Done
**Epic:** [EPC-008](../epics/EPC-008.md)

Confirm and prove that the kit works from scratch with no user configuration,
and that project resources — both new ones and overrides — reach the native
export alongside the built-ins.

## Acceptance criteria

- [x] Built-in resources export with no project configuration present
- [x] A project-only resource appears in the native command list
- [x] A project resource overriding a built-in exports the project body
- [x] Gated resources stay out of the export until their flag is set

## Why

The user's stated expectation: "os built-in vêm from scratch e se o user tem
customização, o setup e o sync também a incluem."

The composition already existed — `ResourceService.load()` merges built-in and
project resources with project winning — but nothing asserted it survived the
*export*. An override that resolves correctly in `get_resource` and then ships
the built-in body natively is exactly the class of silent failure this project
keeps finding ([FND-001](../findings/FND-001.md),
[FND-017](../findings/FND-017.md), [FND-021](../findings/FND-021.md)): correct
in the model, inert in the artefact.

## Verification

`test_sync_service.py` covers a project-only skill reaching the command block
and an overriding skill exporting the project body.
