# PRD: Common Rules MCP Orquestrador

[🏠 Wiki Hub](../README.md)

## 1. O Problema e Visão
O servidor antigo processava pseudocódigo de regras de forma engessada. A visão é criar um **MCP de Orquestração** onde regras, skills, workflows e agentes são recursos independentes (First-class citizens) com metadados YAML e corpos de prompt natural.

## 2. Princípios (Design Principles)
- **Natural language only**
- **Self-aware resources**
- **Progressive disclosure**
- **Tool-agnostic**
- **Predictable outputs**
